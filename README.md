# Warframe Arsenal

Фанатский справочник по Warframe в одной странице: оружие, варфреймы, компаньоны, моды, мистификаторы, конструктор билдов с полярностями и формами, фракции, статус-эффекты, школы фокуса, реликвии, ресурсы, отметки освоения и хроника лора.

- `source.html` — исходный каталог с русскими описаниями добычи.
- `overrides.json` — дополнения из WARFRAME Wiki (переведены): где брать чертежи и детали варфреймов, недостающие картинки.
- `app.html` — оболочка и стили приложения.
- `app.js` — логика: каталог, конструктор билдов, профили.
- `content.js` — фракции, статус-эффекты, школы фокуса, шаблоны рекомендованных билдов.
- `lore.js` — события хроники.
- `config.js`, `supabase.sql` — заготовка облачных аккаунтов (выключена, пока не заданы ключи).
- `build.py` — сборка: тянет свежие данные и иконки из [WFCD warframe-items](https://github.com/WFCD/warframe-items) и собирает `site/`.

Сайт пересобирается GitHub Actions при каждом пуше и каждый понедельник.
